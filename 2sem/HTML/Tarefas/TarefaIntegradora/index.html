Sobre a DevSpace

A DevSpace é uma comunidade criada para ajudar pessoas que estão começando sua jornada no desenvolvimento de software.

Aqui você encontrará dicas de estudo, conteúdos sobre programação e orientação para desenvolver sua primeira aplicação.

Dicas para estudar programação

Confira recomendações para organizar seus estudos:

  • Pratique programação todos os dias.
  • Procure sites que os profissionais recomendam.
  • Faça pequenos projetos para testar seus conhecimentos.
  • Leia a documentação das tecnologias utilizadas.
  • Não tenha medo de pesquisar quando encontrar um erro.
  • Revise os conteúdos estudados regularmente.

Uma rotina de estudos

  1. Estudar o conteúdo.
  2. Observar exemplos.
  3. Praticar no computador.
  4. Corrigir os erros.
  5. Refazer o exercício sem consultar o exemplo.

Tecnologias para começar

Conheça algumas tecnologias importantes para quem está começando:

  • HTML - estrutura das páginas.
  • CSS - aparência e apresentação.
  • Javascript - botões mudanças de foto
A Rede de Desenvolvedores da Mozilla (MDN) é uma plataforma de aprendizagem em evolução para tecnologias da Web e o software que elimina a Web.

Para aprofundar seus estudos, consulta a documentação da MDN
